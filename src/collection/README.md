# 📥 Data Collection (데이터 수집 모듈)

이 폴더는 외부 API를 호출하거나 웹 크롤링을 통해 **원본 데이터(Raw Data)를 수집하는 스크립트**들을 모아두는 곳입니다.

## ⚠️ 작성 규칙
* **재사용성:** 특정 선수의 데이터만 하드코딩해서 가져오기보다는, 시작 날짜(start_date)와 종료 날짜(end_date), 혹은 선수 ID를 파라미터로 받아 유연하게 수집할 수 있도록 함수나 클래스 형태로 작성해 주세요.
* **저장 위치:** 수집된 원본 데이터는 반드시 `../../data/raw/` 경로에 저장되도록 코드를 구성해야 합니다.

## 📄 파일 구성 예시
* `statcast_scraper.py`: `pybaseball`을 활용하여 특정 기간의 투구(Pitch-by-pitch) 데이터를 수집하는 스크립트
* `player_id_mapper.py`: FanGraphs 등 외부 사이트와 Statcast 간의 선수 ID를 매핑하고 병합하기 위한 스크립트
