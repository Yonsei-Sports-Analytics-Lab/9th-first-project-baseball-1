# 🎨 Visualization — 예정

분석 결과를 그림으로 만드는 코드를 두는 폴더입니다. **현재는 비어 있습니다.**

지금까지의 시각화(무브먼트 평면 산점도, 클러스터별 분포, BIC 곡선 등)는 `notebooks/` 의 `DBSCAN_EDA.ipynb`, `GMM_pitch_repertoire.ipynb` 에 있습니다.

## ⚠️ 작성 규칙 (시각화 코드를 추가할 때)

* **독립성 유지:** 전처리·모델 코드와 강하게 묶지 말고, 정제된 DataFrame 이나 `pitcher_clustered.json` 같은 산출물을 입력받아 그림만 그리는 함수로 작성합니다.
* **출력물 관리:** 생성한 이미지(`.png`, `.svg` 등)는 저장소 용량을 차지하므로 가급적 커밋하지 않습니다. 공유가 필요하면 `docs/` 에 꼭 필요한 것만 올립니다.
* **축 방향 통일:** 무브먼트 평면은 x축 `hb_ft`(암사이드 +), y축 `ivb_ft` 로 그려 노트북과 일관되게 유지합니다.
