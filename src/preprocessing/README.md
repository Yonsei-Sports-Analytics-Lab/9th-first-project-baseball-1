# 🧹 Data Preprocessing (데이터 전처리 모듈)

이 폴더는 수집된 원본 데이터를 정제하고, 딥러닝/머신러닝 모델의 입력(Input)으로 사용할 수 있도록 **피처 엔지니어링 및 변환(Transform)을 수행하는 코드**를 관리합니다.

## ⚠️ 작성 규칙
* **모듈화:** 결측치 처리, 스케일링, 파생 변수 생성 등은 각각 독립적인 함수로 나누어 작성해 주세요. (예: `clean_missing_values()`, `scale_features()`)
* **데이터 분리:** 전처리가 완료된 학습용 데이터 세트는 `../../data/processed/` 경로에 저장되도록 합니다.
* **입력 형태 변환:** 시계열 기반의 예측을 위해 데이터를 3차원 배열 형태로 묶거나, 시퀀스 길이를 맞추는 로직이 이곳에 포함되어야 합니다.

## 📄 파일 구성 예시
* `clean_data.py`: 사용하지 않는 칼럼 제거 및 투구 결과(description) 결측치 처리 로직
* `feature_engineering.py`: 기존 지표를 바탕으로 볼 배합 패턴 등 새로운 파생 변수를 생성하는 로직
* `sequence_padder.py`: 모델 입력용 데이터의 시퀀스 길이를 맞추기 위한 마스킹(Masking) 및 패딩(Padding) 처리 모듈
