# 🧠 Models (모델 구조 및 학습/평가 모듈)

이 폴더는 피치 타입 예측 등을 위한 **딥러닝/머신러닝 모델의 아키텍처를 정의하고, 학습(Train) 및 평가(Evaluate)하는 전체 파이프라인**을 보관합니다.

## ⚠️ 작성 규칙
* **구조와 실행의 분리:** 모델을 정의하는 클래스 파일(예: `lstm_classifier.py`)과, 해당 모델을 불러와서 실제로 학습을 돌리는 스크립트(예: `train.py`)를 분리해서 작성해 주세요.
* **하이퍼파라미터 관리:** 배치 사이즈, 에포크, 학습률 등의 파라미터는 코드 중간에 하드코딩하지 말고, 파일 상단의 설정 변수나 별도의 `config` 파일로 분리하여 관리하는 것이 좋습니다.
* **가중치 저장:** 학습이 완료된 모델 가중치(예: `.pt`, `.h5` 파일)는 용량이 클 수 있으므로 `.gitignore`에 등록하여 GitHub에 직접 올라가지 않도록 주의하세요.

## 📄 파일 구성 예시
* `lstm_classifier.py`: 시계열 투구 데이터를 입력받아 다음 구종을 예측하는 LSTM 모델 아키텍처 (PyTorch / TensorFlow)
* `train.py`: `processed` 폴더의 데이터를 불러와 모델을 학습시키고, 클래스 불균형 문제를 해결하기 위한 가중치(Class weights) 적용 로직 등을 포함하는 스크립트
* `evaluate.py`: Test 데이터셋을 바탕으로 모델의 정확도, F1-score 등을 측정하고 Confusion Matrix를 계산하는 스크립트
